## 1. Ringkasan Proyek

**InterviewAI** adalah aplikasi web simulasi wawancara kerja berbasis **suara real-time** dengan pewawancara AI, untuk pencari kerja Indonesia (UI Bahasa Indonesia). Tampaknya proyek skripsi (Fase 6 menyebut format lampiran skripsi, target Black Box ≥ 90%).

**Tech stack:**
- **Frontend:** React 18 + Vite 6 + TypeScript + Tailwind CSS v4, react-router v7
- **Backend:** Node.js + Express 4 + TypeScript (tsx), JWT + argon2, zod, helmet, rate-limit
- **DB:** PostgreSQL (users, sessions, evaluations — 5 migrasi SQL) + MongoDB (transkrip)
- **AI:** Gemini Live API (`gemini-3.1-flash-live-preview`) via **token-broker pattern** — audio langsung browser↔Gemini via WSS dengan ephemeral token; `GEMINI_API_KEY` tidak keluar server. Evaluasi terstruktur (structured output) via model teks terpisah.

**Arsitektur:** monorepo npm workspaces (`frontend/`, `backend/`). Backend modular (auth, jobFields, sessions, gemini). Frontend: pages + features/session (11 komponen sesi) + lib/audio (capture PCM 16kHz, playback 24kHz) + lib/gemini (liveClient 405 baris). Total kode ~4.900 baris TS/TSX. Dokumentasi acuan kuat: `docs/PRD.md`, `docs/IMPLEMENTATION_PLAN.md` (7 fase), design handoff.

**Acceptance criteria:** (a) sesi penuh selesai tanpa transkrip hilang/tertukar; (b) reconnect manual & otomatis pulih; (c) tidak ada WS/mic leak setelah end (cek devtools); (d) evaluasi muncul di DB (Postgres + Mongo). Hasil dicatat di `docs/`.
**Estimasi:** S–M. **Dependensi:** tidak ada. **Prioritas #1** — gerbang sebelum fase lain.
